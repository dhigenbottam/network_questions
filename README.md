# Network Quest

A multiple-choice quiz for Year 7 computer science, covering computer networks. It is a static site: there is no build step, server, or external JavaScript dependency.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository and add `index.html`, `styles.css`, and `script.js` (and this README).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then select **Save**.
5. Once deployment finishes, open the Pages URL shown on that settings page.

The quiz uses no build step, so the three site files can be served directly from the repository root.
